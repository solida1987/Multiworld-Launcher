# Multiworld Launcher 2.9.41

Repository and cleanup follow-up to 2.9.40.

## Changes

- The repository no longer carries artwork, credits, achievement text or
  patch notes for the removed games — only Diablo II content remains.
- The automatic cleanup now also removes the loose game icons in the
  `Assets` folder that the first sweep missed, and it deletes art per file
  so the Diablo II artwork and generic fallback images are kept.
