# Multiworld Launcher 2.9.40

This launcher is now dedicated to Diablo II Archipelago.

## Changes

- **Diablo II only.** All other games have been removed from the launcher:
  the catalog, the plugins and the browse lists now contain only the two
  Diablo II channels (stable and experimental).
- **Automatic cleanup.** On first start this version removes everything the
  old catalog left behind inside the launcher's own folder: installed
  non-Diablo game folders, fetched apworlds and cached artwork. Nothing
  outside the launcher's folder is touched, and Diablo II installs, saves
  and seeds are kept.

If you used the launcher for other games, please use the official
Archipelago Launcher for those going forward.
