# Multiworld Launcher 2.9.44

## Changes

- Removed the directory of third-party Archipelago tools from the Browse page.
  This launcher neither ships nor supports them, and the entries carried no
  descriptions.
- The requirement badge now names the patch level — **Requires D2: LoD 1.10f**
  — since that is the part people get wrong; any other version fails to
  install.
